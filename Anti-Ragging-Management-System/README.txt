ANTI-RAGGING MANAGEMENT SYSTEM

Technology:
PHP, MySQL, HTML, CSS, JavaScript, XAMPP

INSTALLATION:
1. Copy this folder to C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import database/anti_ragging.sql
5. Open http://localhost/Anti-Ragging-Management-System/

http://localhost/Anti-Ragging-Management-System/register.php
